# PAChecker Phase 5 PWA 및 사용성 결정

## PWA 적용 결정

PAChecker는 개인용으로 PC와 iPhone에서 동일 서버를 사용하는 웹앱이므로 설치 가능한 PWA 구성을 적용합니다.

적용 범위:

- Web App Manifest
- 192px 및 512px 앱 아이콘
- iPhone용 Apple Web App 메타데이터와 touch icon
- Service Worker 등록
- 정적 앱 셸 자산의 제한적 캐시
- 홈 화면 실행 시 standalone 표시

캐시하지 않는 대상:

- `/api/` 전체
- 업로드 원본 이미지
- 수행평가 및 알림 데이터 응답
- POST, PUT, DELETE 요청

수행평가 데이터의 정본은 항상 서버 MariaDB이며, 오프라인 캐시를 데이터 동기화 수단으로 사용하지 않습니다.

## 모바일 입력 UX

- 입력 컨트롤은 iPhone 자동 확대를 피하도록 최소 16px 폰트를 사용합니다.
- 주요 터치 동작은 최소 44px 높이를 확보합니다.
- 저장·확정 동작은 긴 폼에서도 찾기 쉽게 배치합니다.
- 이미지 입력은 카메라 촬영과 파일 선택을 모두 허용합니다.
- safe-area 여백과 긴 텍스트 overflow를 고려합니다.

## 목록 및 대시보드

- 목록은 제목·과목·설명·준비물 검색을 지원합니다.
- 과목, 진행 상태, 날짜/제목 정렬을 지원합니다.
- URL query로 과목·상태 보기를 직접 열 수 있도록 합니다.
- 대시보드는 완료 전 수행평가를 날짜와 D-Day 기준으로 정리하고 임박·당일·기한 경과를 구분합니다.

## 설치와 검증 경계

Manifest, 아이콘, service worker, 메타데이터 및 프로덕션 빌드는 로컬에서 검증합니다. 실제 iPhone의 홈 화면 추가와 standalone 실행은 배포된 HTTPS 주소에서 실기기 검증합니다.
